## Severity legend

- **High** — Likely to mask a real bug (None defaults that the runtime
  treats as required strings, dict-of-Any that hides shape mismatches in
  hot APIs).
- **Medium** — Type information loss that erodes downstream inference
  (missing return types, untyped helper calls).
- **Low** — Missing generic type arguments where the actual runtime value
  is well known and the call sites already pass shaped data.

   in `event_store.py:100` and any easy `dict[str, Any]` widenings —
   knocks ~30 errors off the bottom of the table without touching
   semantics.

   `storage/manager.py` plus the `_ensure_table` / `_load_fallback` /

3. **Soundness pass**: address the three flagged **High** issues —
   `vector_store.py:316` (`None.search`), `manager.py:373` (sort key),
   and `user_model_store.py:968` (None defaults on `str` params). Each
   wants a small behavioural change (guard / annotation widening).

   that overlaps with the v2 producer migration. The producers replace
   most callers; killing the v1 store deletes the rest of these errors
