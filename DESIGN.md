# Life OS v2 — Design System

Generated by /plan-design-review on 2026-04-21. Anchor for the Phase 1 web rewrite.

## Principles

1. **Evidence is a feature.** Every insight is tied to its source; every source is one tap away.
2. **Subtraction default.** If an element doesn't earn its pixels, cut it.
3. **One primary action per card.** Everything else is secondary or ghost.
4. **No horoscope.** Never show a state the data can't support (fake bars, decorative charts).
5. **Calm over urgent.** No red triangles, no alarm icons, no urgency bait.
6. **Apple-native references:** Apple Health Summary, Fitness+, Journal, Screen Time, Intelligence Writing Tools.

## Information Architecture

4 tabs: **Now · You · People · Settings** (gear).

- **Now:** action queue. Sections: NOW · UP NEXT · DONE TODAY (collapsed).
- **You:** self-portrait. Sections: When you're at your best · How you write · Your routines · Drifting.
- **People:** contact list. Always starts with "YOU" (outbound style). Then NEEDS ATTENTION · ACTIVE THIS WEEK.
- **Settings:** connectors, preferences, quiet hours, autonomy, data.

## Motion

```css
--motion-micro: 100ms cubic-bezier(0.4, 0, 0.2, 1);
--motion-swap:  180ms cubic-bezier(0.4, 0, 0.2, 1);
--motion-modal: 260ms cubic-bezier(0.16, 1, 0.3, 1);
```

Respect `prefers-reduced-motion`. Never bounce. Never spring.

## Icons

Lucide SVG inline via Jinja helper. Only 16/20/24 px. `stroke-width: 1.5`. Always monochrome via `currentColor`. No filled variants in Phase 1.

## Moment card — states

| State | Appearance |
|---|---|
| Rest | `--bg-raised` + `--elev-1`; no border |
| Hover | `--bg-raised-hover` + `--elev-2`; 100ms transition |
| Focused (keyboard) | Rest + `--elev-focus` ring |
| Draft composing | Draft block shows "Writing a draft..." with 3-dot loader |
| Expanded evidence | Evidence list unfurls below draft block; chevron rotates |
| Pressed primary button | Button scales 0.98, 100ms, returns |
| Being accepted | Card fades opacity 1→0.5, translateY 0→-6px, 150ms, then removed |
| Being snoozed | Card slides right 8px then returns to list under UP NEXT |
| Expired | Never shows to user; goes direct to state=expired in DB |

## Action button hierarchy

Per card:
1. **Primary** — filled, `--primary-action` background, white text. Exactly one per card. Example: `[Send]`, `[Start timer]`, `[Start a message]`.
2. **Secondary** — ghost outline, `--text-primary`, transparent bg. Multiple allowed. Example: `Edit`, `Snooze 3d`.
3. **Destructive/Dismiss** — ghost; hover tinges `--error`. Right-most in the row.

All buttons: `--s-3` horizontal padding, `--s-2` vertical padding, `--r-sm` radius, `--t-15` text, `--w-medium` weight.

## Empty states (template)

```
<title>: one warm sentence
<subtitle>: tertiary, what to expect or where to act
<optional CTA>: only for Settings/connectors empty states
```

Never a cartoon illustration. Never "Oops!" never "Whoops!". Never a "Get Started" button on a non-setup view.

## WCAG AA baseline

- Contrast: ≥ 4.5:1 (verified above)
- Every interactive element has `:focus-visible` + `--elev-focus`
- Semantic HTML: `<main>`, `<nav>`, `<section>` with labels; `<button>` for actions
- Keyboard: Tab to reach, Enter to accept, Esc to cancel inline edits
- Screen readers: `aria-label` on Moment cards summarizing insight + action
- Touch: 36×36 min desktop, 44×44 min any mobile context

## Responsive

- ≥ 1280px: centered 760px max-width content
- 960–1279: same, tighter margins
- 640–959: full-width minus `--s-6` gutter
- < 640: single column, `--s-4` gutter (Phase 1 low-priority)

## Copy voice

- Second-person direct: "You haven't talked to Mike in 18 days."
- Evidence language: "From 4 conversations · Feb 12 – Apr 3."
- Never marketing: no "Unlock", "Supercharge", "Transform".
- Never alarmist: "Dad · 9 days (usual 5)" not "⚠ OVERDUE".
- Microcopy for evidence link explains *why*: "This appeared because cadence dropped 27% below norm."

## What's NOT in Phase 1

- Light theme
- Cmd+K
- Swipe gestures on web
- Rich empty-state illustrations
- Mobile-web polish (iOS native is Phase 2)
- WCAG AAA (AA is the Phase 1 target)
- Avatars / profile pictures
